# Phases P18–P23: Uncertainty and Deployment Loop

## Scope
- P18: Uncertainty estimation and calibration
- P19: Online A/B simulation
- P20–P21: Continuous integration, drift monitoring
- P22–P23: Deployment candidate selection and sensitivity analysis

## Inputs
- Calibrated predictions (`artifacts/p18_uncertainty/calibrated.jsonl`)
- Simulation logs (`artifacts/p19_ab_sim/`)
- Drift signals (`artifacts/p21_drift/`)

## Outputs
- Guardrail reports (`artifacts/tables/p18_p23_guardrails.csv`)
- Drift dashboards (`artifacts/figures/drift/`)
- Deployment shortlist bundles (`artifacts/bundles/p23_deploy_candidates.zip`)

## Acceptance metrics
- Expected calibration error (ECE) ≤ 0.08
- Online lift maintained with ≤ 0.5% guardrail violations

## Commands
```bash
python -m semm.p2.uncertainty --use-existing-artifacts
python -m semm.p2.ab_sim --dry-run
```
