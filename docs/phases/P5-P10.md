# Phases P5–P10: Line and Surface Modeling

## Scope
- Weight calibration (P5)
- Line generation (P6)
- Benchmark suite (P7)
- Surface fitting (P8)
- Correlation analysis (P9)
- Ablation studies (P10)

## Inputs
- `artifacts/p10_real/p4_deltas.jsonl`
- `artifacts/p10_real/generated_paths.jsonl`

## Outputs
- `artifacts/tables/p5_p10_metrics.csv`
- Surface coordinates in `artifacts/p10_real/p8/surface_coords.jsonl`
- Benchmark figures (`artifacts/figures/line_surface/`)

## Acceptance metrics
- Line precision ≥ 0.62
- Surface RMSE ≤ 0.08
- Ablation delta on macro-F1 ≤ 0.02 drop

## Commands
```bash
python -m semm.p1.line --use-existing-artifacts
python -m semm.p1.surface --dry-run
```
