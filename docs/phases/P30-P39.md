# Phases P30–P39: LLM Expansion Roadmap

## Overview
This roadmap introduces an LLM-augmented pipeline that extends SEMM beyond handcrafted policies.

## Targets
- **P30**: Data streaming at ≥ 1 GB/s using structured JSONL feeds.
- **P31**: Differentiable soft-edit surrogate with Pearson r ≥ 0.80 versus ground truth costs.
- **P32**: Encoder heads achieve macro-F1 ≥ 0.55 transfer performance.
- **P33**: Δ-head macro-F1 ≥ 0.60; perplexity reduction ≥ 5%.
- **P34**: +0.05 semantic and +0.05 Jaccard improvement on 1k validation set.
- **P36**: Δφ ≥ 0.05 gain with guardrail violations ≤ 0.5%.
- **P37**: Line-RAG QA accuracy +5 percentage points and cost −10%.
- **P38**: Human evaluation agreement κ ≥ 0.6.
- **P39**: Serving throughput ≥ 1k requests in < 60s with ≥ 30% cache hits.

## Deliverables
- Data schema (`src/semm/p2/llm/data/schema.md`)
